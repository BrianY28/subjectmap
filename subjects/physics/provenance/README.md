# Physics provenance and migration

The physics collection was imported from [BrianY28/physics-map](https://github.com/BrianY28/physics-map) at commit `361e305e8870a917193a0059af3aa1b1b665fef1`. It contains 11 branches, 82 topics, 326 concepts and 228 citation entries.

The upstream project records that its first edition was drafted on 8 November 2026 by DeepSeek V4.1 Flash through Ollama, with outlining, corrections and AI review by Claude. Topic metadata preserves those drafting and review records, including `Claude (AI)` reviewer entries and the original frontier `as_of` dates. Those records do not claim human expert review.

## Preserved records

- [Upstream README snapshot](upstream-README.txt): the original overview and account of how the map was made. It is kept as a text snapshot because its relative links refer to the original repository layout.
- [Upstream review notes](upstream-review-notes.md): the imported record of the original AI review and corrections.
- [Full upstream provenance at the imported commit](https://github.com/BrianY28/physics-map/tree/361e305e8870a917193a0059af3aa1b1b665fef1/provenance): original drafts, feedback and pipeline records not duplicated in SubjectMap.

## Changes made for SubjectMap

The collection now lives under `subjects/physics/` alongside chemistry. Shared build tools generate its index, OPML and local topic pages, while the site presents both subjects from a common selector. Navigation and edit links in the Newton's first law explainer were adapted to the new layout.

This migration is a structural and presentation change, not a new scientific review. It does not advance review dates or replace original drafting and reviewer names. Any later scientific corrections should identify the changed claim and supporting evidence through the normal contribution workflow.
